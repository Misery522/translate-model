# Android 客户端计划入口（原方案已替代）

更新日期：2026-10-09。开发顺序为 **可安装 Android 文字 App → 真机稳定 → 语音**。

## 当前采用的方案

首版已改为原生 `Activity` + AndroidX WebKit 1.14.0 的受限宿主，仅加载 APK
内置界面。已实现 Java 白名单网络桥并生成私人 debug APK，安装后有独立图标和
窗口，不需要外部浏览器；系统 WebView 仍是绘制组件，不是手机端模型。

旧方案中的“固定 Capacitor 8.5.3”“尚无 Java 宿主、Android 工程或 APK”
已经失效，不再作为执行依据。安全审查发现固定 Capacitor 的默认通用桥不能完整
禁用，经用户确认后替换为来源受限的标准消息桥；没有引入或修改其运行时。
