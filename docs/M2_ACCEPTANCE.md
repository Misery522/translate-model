## 已有修复与历史证据

以下为 2026-09-10 / 2026-09-20 已记录的实现与验收，不冒充本轮真机结果：

- 修复首次调度前取消导致运行位无法释放的竞态；旧取消回调不能清理新任务。
- 前端覆盖字符计数、迟到结果、断网清理、超时取消、会话过期、
  XSS 文本显示、PWA 图标及静态壳白名单。
- 旧 Android WebView 缺少 `crypto.randomUUID()` 时，使用
  `crypto.getRandomValues()` 生成 RFC 4122 v4 请求编号；安全随机源完全不可用时保留
  草稿且不进入忙碌状态，不使用 `Math.random()` 等弱随机降级。
- 202 响应体中断、畸形 JSON、未知任务响应保留停止入口，不自动重投；取消必须确认终态。
- 提交、轮询和取消均核对任务/会话/客户端请求身份；首个合法响应的任务代次固定，
  其他任务的结果或取消状态不能解除本轮等待，也不能显示为本轮译文。
- 历史 Python pip-audit 通过；发行前仍须对拟发行提交使用最新数据库复验。
- 当时发现 OpenAPI 开发工具链的 js-yaml 高危拒绝服务漏洞，已定向更新
  @redocly/openapi-core 1.34.20 / js-yaml 4.3.2；未更换主要运行依赖。
- 本机 `qwen3.5:4b` 通过 API 配对、真实翻译、删除会话、退出与推理子进程回收测试。
  HTTP 协议使用 ASGI TestClient，模型调用及监督子进程为真实实现。
- API + 网页静态文件在临时回环端口成功启动，测试端口与测试服务已回收；未停止 Ollama。
- 构建目录包含 React / react-dom / scheduler 的完整许可证文本。
- 生产构建会验证真实 `dist/sw.js`：模板占位符、缓存版本、稳定排序、文件存在性、
  越界路径及静态壳精确清单任一异常都会使构建失败。
- Windows 端已验证 Tailscale Serve 为 `tailnet only`，API 仍仅监听回环地址；
  私人 HTTPS 首页与健康接口返回 200，并保留 CSP、禁止缓存等安全响应头。
