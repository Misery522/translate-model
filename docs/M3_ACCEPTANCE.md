# M3 Windows 文字宠物验收记录

日期：2026-09-10。版本：0.4.0-alpha.1；开发中，尚未正式发行。

## 已验证的源码能力

- 网页与宠物共用 TranslationService、公共 API、useTranslator 和任务结果验证。
- 小窗具备服务地址配置、一次性配对、目标语言、翻译/注解、重试、复制、停止和清空。
- Tauri 配置包含原创角色、置顶窗口、托盘、快捷键、拖动与隐藏；最小权限静态检查。
- 原生 Bearer 仅在 Rust 内存；错误固定脱敏，地址切换需处理旧连接撤销，迟到结果丢弃。
- 普通网页不能用查询参数进入原生模式；Tauri 不注册 Service Worker。
- 前端 162 项模拟 DOM / fake bridge 测试通过，包含 10 项宠物组件测试。
- 桌面配置、图标与 CI 边界检查通过；这不是 Rust 运行证据。
- TypeScript 与生产构建通过；网页构建附 React、scheduler 和 Tauri JS 的完整许可。
- 已核对 CI 提交 ef6a8da 的受限产物与 SHA256，并导入 Cargo.lock 和 Rust 格式化补丁。
  480 个锁条目中只有本项目为本地包，其余均为带校验和的 crates.io 来源；直接版本一致。

## 待完成的发布门禁

- 2026-09-10 的 [Windows CI](https://github.com/Misery522/translate-model/actions/runs/34473789013)
  严格安全审计未通过：6 项停止维护告警（proc-macro-error 与 5 个 unic 包），
  以及 glib 0.18.5 的 RUSTSEC-2024-0429 `unsound` 告警。不能宣称 Rust 依赖无风险。
  该轮在审计处停止，尚未运行 Rust 编译/测试；后续将两者拆成独立任务收集证据，
  最终门禁仍要求两者都成功，不增加忽略项，也不把编译成功当成审计通过。
- 继续核查上游修复、平台可达性，并执行已锁定源码的实际 Rust 格式、编译和测试。
- 审核 Rust 传递依赖的完整版权与许可，随二进制保留；不能用通用 SPDX 正文
  自动替代依赖实际版权文本。此项未完成时不公开分发安装包。
- Windows 安装/卸载、托盘、快捷键冲突、多屏/缩放、隐藏唤回、配对、断网和退出实测。
- 桌面签名与正式分发渠道需独立授权。当前没有完成可安装产品验收。
- 浏览器工具的策略核验不可用，未绕过限制；模拟 DOM 测试不等于实际浏览器验收。

本机没有安装 Rust / MSVC；临时 CI runner 上的工具不修改用户的全局环境。
初次 CI 只上传受限锁文件与格式补丁供审查，不能把该产物当作编译通过。
本阶段工作流不构建或上传 NSIS 安装包；有锁后执行 Rust 编译、测试与严格安全审计。
源码包检查也要求包含桌面锁文件，因此首次无锁引导不应被视作可发布快照。
原应用、原 .venv、Ollama 模型、模型目录和公网配置均保持不变。

## 不在本版能力内

语音、自由聊天、Android/iOS 原生客户端、手机离线推理和连续口译尚未交付。
Android 8+ 是远端客户端开发目标，不是全部手机或 4B 模型的性能承诺。
