## 2. 安装前准备（不需要先安装 App）

- [ ] 最新候选的两类 CI、APK 资源/权限/许可证/调试签名检查通过。
- [ ] 确认 APK 仅由本人通过受控文件传输取得，没有公开上传。
- [ ] 电脑、Ollama、私人 API 和 Serve 可用；模型已安装，不重复下载。
- [ ] 知道从对应 API 的本机交互终端获取新配对码的方法；现在不预生成短期码。
- [ ] 手机安装获得单独明确确认；若未确认，停在此处。

安装确认后：先开启 Tailscale 并确认私人网络在线，再进行 USB 文件传输和该次
来源许可，最后打开 App 配对。无需开启 USB 调试，也不安装桌面构建工具到手机。
之后关闭不再需要的安装来源许可，不公开配对码、私人域名或终端截图。

`INTERNET` 是普通权限，不一定出现授权弹窗；通过 APK 清单和系统应用信息核对。
当前 App 不需要麦克风、存储、悬浮窗、无障碍或后台保活权限。

## 4. 失败记录与完成条件

每个失败只写必要信息：

```text
编号 / 时间：
使用的候选提交与 APK 摘要：
操作步骤（不含配对码、令牌、私人域名或敏感原文）：
预期 / 实际结果：
联网、前后台及重新配对状态：
修复提交 / 回归结果：
```

当前后台策略会清空身份；切去 Tailscale、文件管理器或系统设置也可能触发。
因此先准备网络与安装许可再配对。`FLAG_SECURE` 限制截图，优先用文字描述，
不为取证关闭隐私保护。系统剪贴板、输入法和电脑缓存不属于绝对保密保证。

真机失败先修复并回归，必要时退回私人 PWA；不能忽略 TLS、加载远程 UI 或开放
通用网络桥来“修好”兼容性。取消/注销是有界尽力操作，断线时由后端 TTL 回收，
不能声称 GPU 计算已经在同一瞬间停止。

只有关键项目实际通过、失败已解决、对应提交门禁通过，才能标“Redmi 试用验收
完成”。这仍不等于全品牌兼容、手机离线推理、正式签名或公开发布；这些需要独立确认。
