# 开发路线

这里记录开发顺序和发布门槛，不是已经交付的功能清单，也不承诺固定发布日期。
当前源码包含本地 Gradio 翻译与注解、私人 API 和 React PWA；Windows 文字宠物仍处于
草稿审查与 Alpha 试用阶段。每个阶段应通过独立 PR 和可回退的源码基线。

## 2026-10-08 优先级修订

- Redmi K70（用户报告 HyperOS 3.0.307.0）已配对并能发送；手机译文、弱网、熄屏恢复
  等完整真机验收尚未完成。自动测试与电脑侧访问不能替代真机验收。
- 用户选择优先交付可安装的 Android App，再做语音；因此先推进 M5 文字客户端，
  M4 按住说话后移。保留已有里程碑编号，编号不再表示严格开发顺序。
- 第一版 Android App 使用随安装包分发的本地界面与原生网络桥，不是把私人网址
  塞进外部浏览器。它仍通过私人 HTTPS 访问电脑模型，不能承诺手机离线翻译。
- M3 的稳定依赖升级、许可证与 Windows 验收并行推进；严格 Rust 审计尚未通过时，
  不合并 M3、不构建或分发桌面安装器，也不降低审计门槛。
- `v0.3.0a1` 是已存在的源码标签，不是已发布的 GitHub Release；试用验收、源码标签
  和公开安装包发布分别记录。此次修订不创建新标签或 Release。

## M0：可复现的开源基线

导入经过审查的源码、锁文件、测试和文档；排除私人数据、环境与模型权重。
从全新克隆建立环境，运行普通测试和本机模型验收后，再发布首个稳定基线。

## M1：核心服务化

将翻译核心与 Gradio UI 解耦，引入服务、推理提供商和词库仓储接口。
保留当前格式、术语和清空行为，先证明行为一致，再迁移目录和入口。

## M2：私人 API 与手机 PWA

新增 FastAPI、稳定的请求/结果协议与 OpenAPI 客户端，提供设备认证、请求限流、
超时、取消和脱敏诊断。React PWA 通过经过认证的私人 HTTPS 访问电脑模型。
Tailscale Serve 可作为一种私人部署方式，核心不依赖其专用协议。
电脑关闭时，PWA只能打开缓存界面，不能声称仍可本地推理。

## M3：Windows 文字宠物

采用 Tauri 与共享 React 组件，交付原创角色、托盘、拖动、快捷键和文字气泡。
窗口不可用时可退回普通小窗。宠物是客户端，翻译和有限伙伴对话使用独立工作流。
剪贴板读取需明确用户操作，不增加系统命令执行能力。

## M4：按住说话

先验证本地中英 ASR/TTS 的许可证、准确率、耗时和内存，再完成单段录音翻译。
录音时显示明确状态；每轮有取消与代次保护，避免迟到字幕与播报。
语音质量未达标时保持实验状态，不阻塞文字版本使用。

## M5：Android 远程客户端

通过 Capacitor 复用主要界面，Android Studio 打开仓库内生成的 Android 工程。
产品最低 API 26；框架最低版本不等于全部 Android 品牌均已兼容。
先实现文字翻译、代码注解、配对、地址设置、停止、复制、清空与可恢复错误。
认证令牌仅保存在原生内存，不返回网页脚本，不与文本写入本地存储或系统备份。
原生桥只执行白名单 API 操作，拒绝任意 URL、请求头与重定向；保留证书验证。
先验证生命周期、弱网、安全网络与真机安装，再单独确认签名和公开发布。
麦克风权限与语音随 M4 实施，不为首版文字客户端预先申请。
该阶段依赖电脑推理，不默认启用系统悬浮球、后台持续监听或后台保活服务。

## M6：Android 离线推理

通过 Kotlin/JNI 与 llama.cpp 评估独立 GGUF 模型，候选包括 0.8B 和 2B。
模型独立下载并校验来源、许可、大小与 SHA256；不复制 Ollama blobs。
模型只有通过真机质量、内存、温升、耗电和取消测试后，才作为支持选项发布。
能力不足时仅提供短纯文本翻译，复杂格式和代码注解继续提示需要电脑模型。

每轮开始前锁定推理提供商；请求发送后掉线时，提示用户选择手机重试，
不静默跨模型重跑已经产生结果的任务。

## M7：连续口译及其他扩展

按顺序评估部分转写、WebSocket 字幕、VAD 断句、双人口译、播报打断和回声消除。
其后可考虑 OCR、浏览器扩展、跟读练习与加密的可选词库同步。
系统后台麦克风权限、语音模型许可和移动设备性能需要单独验收。

## 每阶段交付标准

普通测试、格式与术语黄金用例、CI 和依赖审查通过；模型与设备能力提供真实验证
记录。版本说明明确已实现和未验证内容，更新隐私与威胁模型，并提供上一版本回退方法。
GitHub保存源码和发布物，不负责运行用户的 Ollama；模型权重不纳入源码仓库。
